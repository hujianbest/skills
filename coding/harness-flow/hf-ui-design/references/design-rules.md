# 设计层规则（hf-ui-design 配套参考）

本文件是 hf 工作流的"审美/设计方向"参考，随 `hf-ui-design` 分发。

## 1. 美学方向库（先选方向，再写代码）

| 方向 | 一句话定位 | 反模式 |
|---|---|---|
| Editorial 编辑风 | 大标题 + 强排版节奏 + 克制的留白 | 一切元素同字号同粗细 |
| Swiss / 极简 | 网格、无衬线大字号、黑白灰 + 一个强调色 | 渐变、圆角泛滥 |
| Brutalist / Neo-brutalism | 粗边框、硬阴影、直白层级 | 磨皮玻璃拟态 |
| Retro-futuristic | 霓虹 + 深底 + 科技感字体 | 浅底紫渐变 |
| Dark luxury | 真黑/深炭 + 金/琥珀点缀 + 大留白 | 全白高光卡片 |
| Soft / 极简暖色 | 暖单色 + 纸质质感 + 编辑式排版 | 默认 Bootstrap 灰卡片 |
| Organic 有机形态 | 自然色 + 圆润非对称形态 | 对称模板网格 |

选定后：方向写入 `spec.md` UI 设计节与 `DESIGN.md`，评审以它为准。

方向与风格匹配时调用本合集 `ui-ux-pro-max`（240+ 风格、127 字体配对、99 UX 指南，覆盖 web/mobile/desktop），让它先给出一致的设计系统再动工；`frontend-design` 负责最终方向与排版确认。

## 2. Taste 三旋钮（默认 3/2/3，1–5）

- `DESIGN_VARIANCE`：布局/风格偏离度（1 保守 → 5 实验）
- `MOTION_INTENSITY`：动效强度（1 无 → 5 电影感；仅服务交互语义）
- `VISUAL_DENSITY`：信息密度（1 空旷 → 5 高密度）

可在 `DESIGN.md` 中按产品覆盖。

## 3. DESIGN.md 最小结构

- 品牌立场：一句话（"这是一个给 X 的产品，气质 Y"）
- 色彩：主色/背景/强调/文本，hex 或 OKLCH，含 3 档灰阶
- 字体：正文 + 标题配对（serif/sans/mono 组合），含字重与行高
- 标尺：间距 4/8/12/16/24/32、圆角 4/8/12、阴影两级
- 令牌命名：`color.bg.surface` 这类语义名，禁止裸 hex 散落
- 禁止项：至少 3 条（如禁 Inter、禁紫渐变、禁 emoji 图标）

## 4. 反 AI 味清单（评审时逐项过）

- Inter / Roboto 默认字体；无衬线当万能药
- 白底 + 紫色渐变 CTA
- 左侧彩条圆角提示框
- emoji 当图标；无理由发光
- 装饰性动效；大面积玻璃拟态
- 卡片套卡片；空状态无 CTA
- 每节标题都居中；正文用口吻腔

## 5. 截图评审框架（web 与 desktop 通用）

拿到真实渲染截图后按序评审：

1. 方向一致性：截图是否还像选定的方向，还是漂回模板脸
2. 排版：标题/正文层级、行长、字体配对是否成立
3. 空间：间距节奏、对齐网格、留白是否克制
4. 色彩：对比度、令牌是否一致、强调色是否滥用
5. 状态：empty / loading / error 是否完整且可看
6. 平台：web 看响应式与浏览器规范；desktop 看 HIG/Fluent、控件尺寸、标题栏/对话框约定

任何一项出硬伤 → 回实现阶段修复 → 重新截图复验。
