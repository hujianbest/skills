# DietrichGebert / ponytail

来源：[DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail) —— "lazy senior dev"：强制最省的最小可用方案，平均减少 ~54% 代码（最高 94%），兼容 20+ agent。

## 技能清单（相互引用，建议整组使用）

- **ponytail**：主技能，极简编码纪律（lite/full/ultra 三档强度）
- **ponytail-review**：用极简标准审查代码
- **ponytail-audit**：审计存量代码的过度工程
- **ponytail-debt**：识别并偿还"过度工程债"
- **ponytail-gain**：量化极简化的收益
- **ponytail-help**：技能使用帮助与路由

> 与 hf 主链互补：适合作为编码阶段的"极简化过滤器"，不替换 hf 的流程纪律。
