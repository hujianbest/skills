# writing-clearly-and-concisely

来源：[obra/the-elements-of-style](https://github.com/obra/the-elements-of-style)。把 William Strunk Jr. *The Elements of Style*（1918，公有领域）做成 agent skill。`brainstorming` 写设计文档时会检测并调用它。

针对「句子正确但读不懂」：主动语态、正面陈述、具体用词、删掉多余的话。完整规则在 [elements-of-style.md](elements-of-style.md)（约 12k tokens，只在真正写/改散文时再读）。

中文口语化去 AI 腔仍用已有的 [`human-writing`](../human-writing) / [`humanizer-zh`](../humanizer-zh)；本技能管的是结构清晰和信息密度，两者可以叠用。
